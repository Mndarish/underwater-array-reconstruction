# Input data

Place the three input files here (they are git-ignored by default):

| File | Contents |
|------|----------|
| `track.csv` | Ship GPS track (`x`, `y`) |
| `transmissions.csv` | 6 transmitter locations (`x`, `y`) |
| `timings.csv` | Arrival times `t11, t12, ... t61, t62` for 1926 sensors |
